# Muhammad Faiz Alam — Portfolio Website

A personal portfolio website built to showcase my background, skills, and projects as a backend software engineer focused on Java, Spring Boot, and fintech-oriented systems.

🔗 **Live site:** https://imfaiz56.github.io/portfolio-website/

## About

This project was built as part of the GIST (Global Institute of Science & Technology) Full-Stack Web Development internship — Task 1: Personal Portfolio Website.

## Features

- Responsive one-page layout (About, Skills, Experience, Projects, Education, Contact)
- Dark, backend-engineer-themed design with animated hero background
- Scroll-based section highlighting in the navigation bar
- Mobile-friendly navigation menu with a working toggle
- Scroll progress indicator
- Copy-to-clipboard email button
- Scroll-reveal animations, respecting `prefers-reduced-motion` for accessibility

## Tech Stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox, keyframe animations)
- Vanilla JavaScript (Intersection Observer API, Clipboard API)
- Google Fonts (Space Grotesk, IBM Plex Sans)

## Setup / Run Locally

This is a single static HTML file with no build step or dependencies.

1. Clone the repository:
   ```
   git clone https://github.com/imfaiz56/portfolio-website.git
   ```
2. Open `index.html` directly in a browser, or use a local dev server (e.g. VS Code's Live Server extension) for the best experience.
